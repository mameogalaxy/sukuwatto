# すくわっと — AR ぬりえ Web アプリ

スマホやタブレットで、かわいいキャラクターを **ぬりえ** して、**AR（カメラ）** で
現実の世界に飛び出させて遊べる Web アプリです。ビルド不要・依存ライブラリなしの
静的サイトなので、そのまま GitHub Pages などで公開できます。

## できること

2 つのモードで遊べます。

### 🪄 マジック いろチェンジ（AI 不要）
撮った写真の中のモノをタッチすると、**その点と「似た色」の範囲だけ**を選び、
**影や質感（明るさ）はそのままに色だけ置き換え**ます。＝本当に色違いのモノに見える。
自分の持ち物の色を変えて遊べます。

- 📷 カメラで撮る / 🖼 写真を選ぶ
- 👆 変えたいモノをタッチ → 🎨 色を選ぶ → その場で色が変わる
- 「えらぶ ひろさ」スライダーで選択範囲を調整、もどす、保存・シェア
- すべてブラウザ内の画像処理で完結（サーバー・モデル不要）

### 🎨 AR キャラぬりえ
キャラクターを選ぶとすぐにカメラが起動し、**空間に浮かんだキャラを指でその場で塗る**
「ライブ AR ぬりえ」です。

- 🎨 **AR ライブぬりえ** — 浮かんだ SVG 線画キャラを、塗りたい場所をタッチして色付け
  - キャラクター: すらいむ / かぼちゃまじょ / おばけ / おほしさま
  - 12 色パレット・けしゴム・もどす
- 👆 **なぞって塗る** — 指を滑らせると、触れた場所が次々に色づく
- ✨ **キラキラ演出** — 塗るたびに星と粒がはじけ、全部塗ると喜んでジャンプ＆お祝い
- 🫧 **生きてるみたいに動く** — 呼吸・ゆらゆらの待機アニメーション
- ✌️ **2 本指で操作** — 移動 / 拡大縮小 / 回転（リセットボタンで中央へ）
  - 塗っている間はふわふわが止まり、塗りやすい
  - 端末の傾きに合わせて少し揺れ、空間に置いた感を演出（Android）
- 📷 **さつえい** — カメラ映像 + 塗ったキャラを合成して保存・シェア（Web Share 対応端末）
- カメラが使えない環境では、背景なしでそのまま塗って保存できます

## つかいかた

1. キャラクターを選ぶ → カメラが起動し、目の前にキャラが現れる
2. 色を選んで、キャラのぬりたいところをタッチ（その場で色づく）
3. 2 本指で動かしたり、大きさ・向きを調整
4. シャッター（◯）で記念撮影

## 開発・公開

ビルド工程はありません。ファイルをそのまま配信するだけで動きます。

```bash
# ローカル確認（どれか1つ）
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

> ⚠️ **カメラと端末センサーは HTTPS（または localhost）でのみ動作します。**
> 公開時は GitHub Pages など HTTPS のホスティングを使ってください。

### GitHub Pages で公開する例

1. リポジトリの Settings → Pages
2. Source を `Deploy from a branch` にし、対象ブランチ / `root` を選択
3. 発行された URL をスマホで開く

## ファイル構成

```
index.html              画面（タイトル / ぬりえ / AR）とモーダル
css/styles.css          スタイル
js/templates.js         ぬりえテンプレート（SVG）とパレット
js/coloring.js          ぬりえロジック（塗り・けし・もどす・書き出し）
js/ar.js                AR（カメラ合成・ジェスチャ・撮影）
js/app.js               画面遷移と全体の組み立て
manifest.webmanifest    PWA マニフェスト
```

## 技術メモ

- 純粋な HTML / CSS / JavaScript のみ（フレームワーク・ビルド不要）
- AR は WebXR ではなく **カメラ映像 + ビルボード合成**方式を採用し、
  幅広い端末で動くようにしています（`getUserMedia` + `Canvas`）。
- iOS 13+ ではモーションセンサー利用に許可が必要なため、AR 起動時に
  `DeviceOrientationEvent.requestPermission()` を呼び出します。
