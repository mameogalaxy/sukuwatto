# 🪞 手話ミラー（Shuwa Mirror）

カメラを“鏡”に見立て、**自分の手の動きをAR検出して見本と照合**しながら、
手話を体験的に・段階的に・楽しく覚えられる学習アプリです。

> 予習 → レッスン（カメラで練習）→ 復習 → テスト → 会話シミュレーション
> という流れで、最終的に「手話で会話できる」ことを目指します。

## 特長

- **📷 AR手話練習** — Webカメラで手の21関節をリアルタイム検出（MediaPipe Hands）。
  見本と同じ手の形ができているかを採点し、「人さし指を立てて」など具体的にフィードバック。
- **📚 段階的レッスン** — あいさつ → 自己紹介 → よく使う言葉 → 気持ち → 数字 → 指文字。
- **🔁 復習（間隔反復／SRS）** — 覚えた手話を忘れたころに自動で出題。
- **📝 テスト** — 見本から言葉を当てる4択クイズで理解度チェック。
- **💬 会話シミュレーション** — 相手の手話を読み取り、正しい返事を選んで会話を進めるゲーム。
- **📈 進捗・連続学習日数** — ブラウザ内（localStorage）に保存。

## 使い方（ローカル実行）

カメラ機能は `https` か `localhost` でのみ動作します。簡易サーバーで開いてください。

```bash
# このフォルダで
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

スマホで試す場合も `localhost`／`https` 環境が必要です（カメラ許可を求められたら「許可」）。
カメラが使えない環境では「カメラなしで覚えた」ボタンで見本学習に切り替わります。

## 構成

```
index.html          画面の土台＋MediaPipe読み込み
css/styles.css      スタイル（モバイルファースト）
js/
 ├ main.js          ハッシュルーター＋下部ナビ
 ├ data.js          手話データ・ステージ・会話シナリオ
 ├ storage.js       進捗保存（localStorage・SRS）
 ├ handpose.js      MediaPipe Hands ラッパー＋手形の照合
 ├ ui.js            DOM生成などの共通ヘルパー
 └ views.js         各画面（ホーム/学ぶ/練習/復習/テスト/会話）
```

## プライバシー

カメラ映像は**端末内のブラウザだけで処理**され、サーバーへ送信・保存されません。

## 今後の発展メモ

- 手形だけでなく「動きの軌跡」も照合して動作系の手話の判定精度を上げる
- 各手話に実写真／動画の見本を差し込む（`signCard` の表示部を拡張）
- 手話語彙の追加（`js/data.js` に追記するだけで増やせる）

---

※本アプリの手話の説明は日本手話の基本例です。表現には地域差・個人差があります。
