# すくわっと — AR ぬりえ Web アプリ

スマホやタブレットで、かわいいキャラクターを **ぬりえ** して、**AR（カメラ）** で
現実の世界に飛び出させて遊べる Web アプリです。ビルド不要・依存ライブラリなしの
静的サイトなので、そのまま GitHub Pages などで公開できます。

## できること

- 🎨 **ぬりえ** — SVG 線画のキャラクターを、塗りたい場所をタッチして色付け
  - キャラクター: すらいむ / かぼちゃまじょ / おばけ / おほしさま
  - 12 色パレット・けしゴム・もどす・クリア
- 📷 **AR ビュー** — 塗ったキャラを背面カメラの映像に重ねて表示
  - ドラッグで移動 / 2 本指ピンチで拡大縮小 / 回転 / 中央リセット
  - 端末の傾きに合わせて少し動き、空間に置いた感を演出
  - シャッターで写真として保存・シェア（Web Share 対応端末）

## つかいかた

1. キャラクターを選ぶ
2. 色を選んで、塗りたいところをタッチ
3. 「AR で みる」を押す → カメラが起動し、キャラが目の前に現れる
4. シャッター（◯）で記念撮影

## 開発・公開

ビルド工程はありません。ファイルをそのまま配信するだけで動きます。

```bash
# ローカル確認（どれか1つ）
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

> ⚠️ **カメラと端末センサーは HTTPS（または localhost）でのみ動作します。**
> 公開時は GitHub Pages など HTTPS のホスティングを使ってください。

### GitHub Pages で公開する例

1. リポジトリの Settings → Pages
2. Source を `Deploy from a branch` にし、対象ブランチ / `root` を選択
3. 発行された URL をスマホで開く

## ファイル構成

```
index.html              画面（タイトル / ぬりえ / AR）とモーダル
css/styles.css          スタイル
js/templates.js         ぬりえテンプレート（SVG）とパレット
js/coloring.js          ぬりえロジック（塗り・けし・もどす・書き出し）
js/ar.js                AR（カメラ合成・ジェスチャ・撮影）
js/app.js               画面遷移と全体の組み立て
manifest.webmanifest    PWA マニフェスト
```

## 技術メモ

- 純粋な HTML / CSS / JavaScript のみ（フレームワーク・ビルド不要）
- AR は WebXR ではなく **カメラ映像 + ビルボード合成**方式を採用し、
  幅広い端末で動くようにしています（`getUserMedia` + `Canvas`）。
- iOS 13+ ではモーションセンサー利用に許可が必要なため、AR 起動時に
  `DeviceOrientationEvent.requestPermission()` を呼び出します。
